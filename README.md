# blog-project-with-DRF

This is a blog project that provides APIs for creating posts and comments and delete theme or update theme and retrieve theme and it provides APIs for sign up and login and refresh access token.

## Requirements

* Python 
* PostgreSql

## Installing

1. copy the repository

```bash
git clone [https://github.com/farhan2113/blog-project-with-DRF.git](https://github.com/farhan2113/blog-project-with-DRF.git)
```

2. create virtual environment 

```bash
python3 -m venv .venv
```

3. install packages

* Django
* DRF
* python-dotenv
* psycopg
* djangorestframework-simplejwt
